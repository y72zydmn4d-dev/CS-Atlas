# Page archetypes

| Archetype | Observed purpose | Structural markers | Atlas interpretation |
| --- | --- | --- | --- |
| TUTORIAL_CATALOG | Discover subjects | Category groups, search/filter, compact links | `/learn` grouped subject catalog |
| SUBJECT_HOME | Orient within one subject | Intro, start/continue, curriculum, activities | One truthful overview of available surfaces |
| LESSON | Teach one ordered unit | Title, prev/next, sections, examples, exercise | Three-column tutorial workspace |
| SUB_LESSON | Split a dense chapter | Same sequence/navigation as lesson | Ordinary lesson manifest item |
| EXERCISE_INDEX | Practice by chapter | Filter, completed count, topic groups | Projection over canonical Exercise records |
| EXERCISE | One retrieval task | Prompt, answer, feedback, next | Existing Atlas Exercise route/workspace |
| EXAMPLES_INDEX | Browse runnable patterns | Group/search examples | Authored reusable Example records |
| QUIZ | Assess a section/subject | Start, question count, score/result | Evidence-backed quiz groups |
| REFERENCE_INDEX | Find symbols quickly | Dense categories/tables/search | Typed reference catalog |
| REFERENCE_TABLE | Scan many entries | Compact rows, stable headings | Accessible data table |
| REFERENCE_ITEM | Explain one symbol/API | Signature, concise semantics, links | Reference detail record, not lesson |
| SYLLABUS | Explain outcomes/scope | Modules, outcomes, activity inventory | Subject-home curriculum overview |
| STUDY_PLAN | Pace/assign a curriculum | Schedule/progress/assignment model | Existing Atlas plan, kept learner-centered |
| EDITOR / TRY_IT | Edit-run-observe | Source, run, result, reset | Capability-aware Atlas example runner |
| SPECIAL_INTERACTIVE | Visualize or challenge | Topic-specific state and controls | Generic DSA visualization contracts |

Template use is inconsistent across subjects. Newer subject families tend to have deeper curriculum and fuller activity systems; data/AI subjects are often shallower or nested under Python. Atlas should encode availability explicitly rather than infer it from a template.
