# W3Schools / Atlas comparison matrix

This compares capability patterns only. It contains no copied lesson, example, exercise or quiz content.

| Capability | Observed W3Schools pattern | Current Atlas state | New Atlas implementation | Atlas-specific improvement |
| --- | --- | --- | --- | --- |
| Tutorial Catalog | Large grouped/filterable subject inventory | Flat projected lesson list | Grouped subject catalog with status/search | Canonical Concepts and honest maturity |
| Subject Curriculum | Subject sidebar with chapter headings | Domain topic ordering | Typed sections, lesson manifests and subject home | Prerequisites and cross-feature relations |
| Lesson Navigation | Active sidebar plus previous/next | Previous/next within legacy domain | Persistent searchable curriculum and mobile drawer | Completion evidence and stable aliases |
| Examples | Embedded examples plus examples index | Worked/code blocks | First-class Example records and lesson blocks | Reuse without duplicate authored source |
| Interactive Editor | Dedicated Try-It/compiler routes | Practice QuickJS Worker; lesson code unavailable | Capability-aware example runner and Playground links | Explicit runtime/security provenance |
| Exercises | Chapter-aligned hubs/items | Canonical Exercise catalog | Subject/section projections and inline checkpoints | Same evidence and version policy |
| Quiz | Separate subject route | No subject quiz manifest | Section/subject quiz groups | Canonical Concept evidence, no second score store |
| Reference | Dense indexes/tables/items | Citations and sources only | Typed reference categories, tables and detail routes | Links back to Concepts/lessons/problems |
| Progress | Optional account-linked completion/XP | Private local evidence | Derived local subject/lesson progress | Transparent evidence, no opaque gamified score |
| Mobile | Curriculum collapses; editor can reorient | Responsive shell and article | Accessible curriculum drawer and folded right rail | Global and tutorial nav cannot crowd each other |
| Search | Site/tutorial search | Unified deterministic Atlas + local Library | Subject/section/lesson/reference documents | Multi-entity canonical result grouping |
| DSA/AI depth | Uneven, often introductory/nested | Strong concepts but few Learn lessons | Deep manifests with representative authored lessons | Problems, visualizations, math and roadmap links |
| Routes | Historical extensions and mixed conventions | Stable App Router slugs | `/learn/<subject>/<lesson>` plus aliases | Versioned deterministic migration map |
